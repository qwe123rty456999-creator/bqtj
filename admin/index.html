4缓存与刷新

改完内容发现线上还是旧的？点下面的按钮，全站访客的缓存会一起换新， 不用再去腾讯云控制台清缓存。
· 原理：把 sw.js 里的版本号 +1 提交到 GitHub。访客的 Service Worker 发现版本变了，下次打开页面就会重新下载整站（那一次会稍慢），之后照常秒开。
· Cloudflare Pages 需要约 1 分钟部署；腾讯云 EdgeOne 节点的副本最多 60 秒自动过期，不用管。
· 这个按钮直接改 GitHub 上的 sw.js，本地仓库记得先 git pull 再继续改代码。
