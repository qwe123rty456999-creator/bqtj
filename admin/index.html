🛠 上传助手

在浏览器里选文件 → 小文件直接提交到 GitHub 仓库 → Cloudflare 自动重新部署，约 1 分钟上线。

🔒
本页不在导航里，也不会被搜索引擎收录。GitHub 令牌只保存在你这台浏览器的本地存储中， 不会写进仓库、不会发给任何第三方。建议用 Fine-grained PAT，只勾选 bqtj 这一个仓库、 只给 Contents: Read and write 权限。

1连接 GitHub 仓库

仓库：—

尚未连接
创建地址：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → 仓库访问选 Only select repositories → 勾 bqtj → 权限 Contents: Read and write
去创建令牌 ↗

2选择文件

把文件拖进来，或点击选择。系统会按体积自动分流： ≤ 10 MB 走 GitHub 直传； > 10 MB 走网盘（硬盘版游戏包、视频都在这类）。

📁
拖文件到这里，或点击选择 支持多选 · 字幕 .ass/.srt · 图片 · 视频 · 压缩包
字幕一般填 files/subs/作品名；其它填 files/uploads
文件名里没有 简/繁/CHS/ja 这类标记时，用这个兜底

3大文件 → 网盘（硬盘版游戏包 / 视频）

—

打开网盘上传页 ↗
（还没有超过 10 MB 的文件）

4生成站点条目

网盘上传完，拿到「分享链接」和「提取码」后填在这里，点一下就直接写进站点数据文件， 首页和列表页立刻更新。

在左边填几项，这里会实时显示将要写入的 JSON。
