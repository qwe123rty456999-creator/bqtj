⚙️ 上传设置

只配一次。需要一个 GitHub 令牌 —— 上传就是靠它写入仓库的，没法省略。 令牌只保存在你这台浏览器的本地存储中，不会写进仓库、不会发给任何第三方。

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → 仓库访问选 Only select repositories → 勾 bqtj → 权限 Contents: Read and write

1上传字幕

把字幕文件拖进来，或点击选择（支持多选）。单个文件上限 20 MB， 超过的会被标出来。上传后会自动追加到字幕库索引并触发部署。

📝
拖字幕文件到这里，或点击选择 .ass · .ssa · .srt · .vtt · .sub · .idx · .sup
一个文件夹 = 一部作品，例如 files/subs/孤独摇滚。 保持 files/subs/ 不变的话，文件会落在字幕根目录（归入「未分类」）。
文件名里有 简/繁/CHS/ja 这类标记时会自动识别； 没有标记就用这里选的兜底。

3命名建议

文件名带的信息越多，字幕库的搜索和语言识别就越准。

较好的命名： 孤独摇滚 第01话 [简][星空字幕组].ass Bocchi the Rock 01 [繁中].ass 作品名 第03话 [简繁][字幕组].srt 不推荐的命名： 1.ass ← 搜不到，也认不出语言 subtitle_final_v2.ass ← 同上 识别规则（看文件名里的标记，顺序从上到下）： 简繁 / 简+繁 / CHS&CHT / GB&BIG5 → 简繁 中日 / 日中 / JPSC → 中日 简 / 简体 / CHS / GB / GBK → 简中 繁 / 繁體 / CHT / BIG5 → 繁中 日语 / JP / JPN → 日语 英语 / ENG → 英语 zh-Hans / zh-CN → 简中 zh-Hant / zh-TW / zh-HK → 繁中 都没标？上传时用「这批字幕的语言」下拉框兜底。
