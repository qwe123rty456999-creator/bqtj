# 直链方案：让访客点一下就开始下载

> 目标：访客在站点上点「下载」→ 浏览器**立刻开始下载**，不跳网盘页、不输提取码。

## 结论：用 OpenList Worker（开源，免费）

**工具**：[OpenListTeam/OpenList-Worker](https://github.com/OpenListTeam/OpenList-Worker)
—— OpenList（原 Alist）官方出的 **Serverless 版**，后端从 Go 重写成 TypeScript，
可以跑在 **Cloudflare Workers**（免费版**不需要绑银行卡**）、腾讯云 EdgeOne、阿里云 ESA。
文档：<https://doc.oplist.org/ecosystem/official_worker>

它内置 **81 个存储驱动**，其中就有 **123云盘（开放平台 / 分享）**，核心能力包括：

- 统一目录树浏览
- **「流式传输与直链跳转」**
- **「生成带有效期、密码与权限控制的分享链接，支持匿名访问与目录分享」**

### 为什么它比"网盘直链解析工具"靠谱

网上那些「网盘直链解析」站和油猴脚本**不要用**：

| 问题 | 说明 |
|---|---|
| 需要你的账号 Cookie | 想解析直链就得拿你的登录态，放到公开网页 = 把网盘账号交出去 |
| 随时失效 | 网盘一改接口就挂，没人维护 |
| 可能被劫持 | 流量过第三方服务器，可能插广告、记录下载 |
| 违反条款 | 属于逆向接口，账号有风险 |

OpenList 不一样：**开源、官方维护、跑在你自己的 Cloudflare 账号里**，没有第三方经手。

### 技术上的关键优势

```
访客点下载
   ↓
Cloudflare Worker （只做一次 302 跳转，几个 KB）
   ↓
123云盘 CDN  ← 文件字节从这里出，国内速度快
```

Worker **不搬运文件内容**，只返回一个 302 重定向。所以：

- Cloudflare 免费版 10 万请求/天绰绰有余
- 国内访客的下载速度由 123云盘 CDN 决定（快），不受 Cloudflare 国际线路拖累
- Worker 本身不消耗带宽费用

## ⚠️ 必须先知道的三个限制

### 1. 123云盘的「直链」是 VIP 付费功能

OpenList 文档原文：

> 使用直链：默认禁用，返回普通下载链接。**启用后，返回 CDN 直链，需要开通 VIP，会消耗直链流量包。**
> 需要用户手动启用直链空间：进入 123 网盘官网，右键根目录下的文件夹，选择 `启用直链空间（VIP）`。

不开 VIP 时 OpenList 返回的是「普通下载链接」——能下载，但速度受免费账号限制。

### 2. 123云盘官方明文禁止拿来做分发服务

123 开放平台文档的警告原文：

> 请规范使用帐号，包含但不限于 `多人共享使用`、`图床、软件床` 和 `视频外链到视频网站播放`
> 等分发服务……导致帐号被封禁的，后果自负！

**把 123云盘当作公开分享站的后端，是踩在这条线上的。** 有封号风险，请自行权衡。
如果只是小范围、低频分享，风险相对低；一旦有流量，风险就上来了。

### 3. 开放平台要申请

访问 <https://www.123pan.com/developer>，签开发者协议 → 填材料 → 等审核，
`client_id` 和 `client_secret` 会发到你的邮箱（记得看垃圾箱）。

## 三条路对比

| | A. OpenList Worker<br>+ 123云盘 | B. 123云盘 VIP<br>官方直链 | C. 本机 OpenList<br>+ Cloudflare Tunnel |
|---|---|---|---|
| 直链 | ✅ | ✅ | ✅ |
| 花钱 | 免费（Workers/D1/KV 免费额度够用） | 需买 VIP + 直链流量包 | 免费 |
| 是否需要电脑常开 | 否 | 否 | **是** |
| 容量 | 网盘容量 | 网盘容量 | **你自己的硬盘** |
| 国内速度 | 快（走 123 CDN） | 快 | 受家宽**上行带宽**限制 |
| 合规/封号风险 | ⚠️ 有 | ⚠️ 较低（官方功能） | 无 |
| 搭建难度 | 中（约 20 分钟） | 低 | 中 |

**建议顺序**：先按 **A** 零成本搭起来验证效果；如果发现风控或速度不行，再考虑 **B**（花钱买稳定）。
**C** 适合大文件多、又不想花钱、且电脑能常开的情况。

## 路线 A 部署步骤（Cloudflare Workers）

### 前置
- 一个 Cloudflare 账号（你已有）
- 一个 GitHub 账号（你已有）
- 123云盘开放平台的 `client_id` / `client_secret`

### 1. Fork 仓库
把 <https://github.com/OpenListTeam/OpenList-Worker> Fork 到你自己账号。
（直接选上游仓库会报「无法获取存储库内容」，必须先 Fork）

### 2. 申请 123 开放平台密钥
<https://www.123pan.com/developer> → 签协议 → 填表 → 等审核 → 收邮件拿密钥。
同时在 <https://www.123pan.com/Setting> 找到**账号ID**（申请时要填「云盘UID」）。

### 3. 在 Cloudflare 创建 Worker
Workers & Pages → **创建应用** → **连接到 GitHub** → 选你 Fork 的 `OpenList-Worker`，
构建参数保持默认：

| 配置项 | 值 |
|---|---|
| Framework preset | `None` / `Workers` |
| Build command | `pnpm run build` |
| Deploy command | `npx wrangler deploy` |
| Production branch | `main` |

### 4. 配环境变量
Worker → 设置 → **变量和机密**，至少要有 `DB_FORMAT`、`DB_DRIVER`（详见
<https://doc.oplist.org/ecosystem/official_worker/guide_env>），另外加上 `JWT_SECRET`。

### 5. 绑定 D1 / KV
设置 → **绑定**：`DB_FORMAT=d1` 就绑一个 D1（命名空间写 `DB`），`kv` 同理。
D1 可以不填 `database_id`，Wrangler ≥ 4.45 会自动创建。

### 6. 绑定自定义域名
设置 → **域名和路由** → 加 `ol.bqtj.cc.cd`（或 `dl.bqtj.cc.cd`）。
因为 `bqtj.cc.cd` 的 NS 已在 Cloudflare，**CNAME 会自动创建**，不用手写。

### 7. 首次访问初始化
打开 `https://ol.bqtj.cc.cd`，会进安装向导，设管理员账号密码。

### 8. 挂载 123云盘
后台 → 存储 → 添加 → 选 **123 开放平台** → 填 `client_id` / `client_secret` / 根文件夹ID。
根文件夹ID 取网址里 `homeFilePath=` 后面那串数字，或右键文件夹「复制文件夹ID」。

### 9. 生成分享链接给站点用
OpenList 里给目录建一个**分享链接**（可设密码、有效期），
把链接填进本项目的条目表单 → 访客点一下就能看到文件并下载。

> 想更彻底：直接放 OpenList 的 `/d/路径` 直链，点击即下载。
> 但**不建议**——没有防盗链，容易被刷流量；用带密码的分享链接更安全。

## 站点这边怎么接

不用改代码。上传助手第 4 步的「网盘分享链接」填 OpenList 分享地址即可；
**提取码留空时，卡片上的按钮会显示成「直接下载」**。
`pan.name` 改成 `OpenList` 之类会显示得更准确。

## 备选：其它能出直链的存储

如果不想承担 123云盘的封号风险，OpenList 也支持这些后端：

- **对象存储**：S3 兼容（阿里云 OSS / 腾讯云 COS / MinIO）、又拍云 USS —— 最合规，但需实名认证，免费额度有限
- **其它网盘开放平台**：阿里云盘、夸克、115、天翼云盘、迅雷云盘
- **GitHub Releases**：OpenList 有 `GitHub Releases` 驱动，单文件 ≤ 2 GiB，免费
  （注意：浏览器**不能**直传 Release，要用命令行 `gh release upload` 或网页面传）
