关于本站

纯静态站点：没有后端服务，也没有由数据库驱动的页面 —— 所有页面、样式脚本和字幕索引 都是 GitHub 仓库里的文件。改内容就是往 GitHub 推一个提交，Cloudflare Pages 收到后自动部署， 大约一分钟生效。

页面本身很小：十来个 HTML 壳，加上几个 JS / CSS 和两个索引 JSON（字幕、游戏）， 压缩后总共不到 100 KB。列表、详情、歌词都是浏览器拿到索引之后现渲染的， 所以加一条字幕不需要生成任何新页面。

对外访问经过 腾讯云 EdgeOne 加速。因为域名没有做 ICP 备案，按规则只能用中国大陆以外的节点， 所以国内直连通常有三百多毫秒的延迟。bqtj.cc.cd 是免费域名服务商 DNSHE 提供的二级域名， 由于国内网络问题无法正常访问。

Service Worker：由于海外节点速度慢，因此设置了 Service Worker。 第一次打开站点时，浏览器会把所有页面和索引预缓存到本地，之后在站内点击完全不再发网络请求 （0 毫秒）；数据每 10 分钟在后台静默刷新一次，所以内容最多旧 10 分钟。 第一次会稍慢一点，之后就都是秒开。

下载统计用一个 Cloudflare D1 数据库，只在有人真的下载字幕文件时记一笔， 同一访客 12 小时内下载同一字幕只算一次 —— 数字更接近「有多少人下过」，而不是「被点了多少下」
