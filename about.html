关于本站

纯静态站点：没有后端服务，也没有由数据库驱动的页面 —— 所有页面、样式脚本和字幕索引 都是 GitHub 仓库里的文件。改内容就是往 GitHub 推一个提交，Cloudflare Pages 收到后自动部署， 大约一分钟生效。

页面本身很小：十来个 HTML 壳，加上几个 JS / CSS 和两个索引 JSON（字幕、游戏）， 压缩后总共不到 100 KB。列表、详情、歌词都是浏览器拿到索引之后现渲染的， 所以加一条字幕不需要生成任何新页面。

bqtj.top 的对外访问经过腾讯云 EdgeOne 加速，速度较 Cloudflare 提升约 28%。 由于该域名未办理 ICP 备案，按规则只能使用中国大陆以外的节点（通常是新加坡服务器）， 因此国内直连延迟一般在 200 多毫秒。bqtj.cc.cd 使用了免费域名服务商 DNSHE 提供的二级域名； 受国内网络问题影响，该域名无法正常访问。

Service Worker：由于海外节点速度较慢，站点启用了 Service Worker。 首次打开时，浏览器会将所有页面和索引预缓存到本地，之后在站内点击不再发起网络请求； 数据每 10 分钟在后台静默刷新一次，因此内容最多滞后 10 分钟。 首次访问会稍慢，之后基本都能秒开。

下载统计用一个 Cloudflare D1 数据库，只在有人真的下载字幕文件时记一笔， 同一访客 12 小时内下载同一字幕只算一次 —— 数字更接近「有多少人下过」，而不是「被点了多少下」
